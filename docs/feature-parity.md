# Feature coverage and comparison

Publisher pages checked on **15 October 2026**. Luma coverage describes the independent **0.13.0 preview**, including features whose targeted live checks are still pending. A present button or passing replay is not evidence of complete protocol coverage. Luma has no paid feature tier.

## What the published products describe

These are publisher descriptions, not independent accuracy guarantees. The comparison does not copy another application's implementation or catalogs.

| Product and primary source | Published capabilities relevant to this comparison | Boundary of Luma's implementation |
| --- | --- | --- |
| [A2Tools](https://a2tools.app/) | Free live DPS, skill/rotation analysis, saved encounters, per-fight ping, second-PC OBS, uploaded logs/class statistics, pet-soul tracking and event plugins. | Luma has its own local meter, event tools, observed pet progress and measured TCP RTT. OBS remains same-PC. Its community summaries are not that provider's packet-recomputed logs or class-statistics dataset. |
| [Abyss Logs](https://github.com/karim-mo/aion2-abysslogs-dps-meter) | Free overlay, shareable encounters and leaderboards; skill/buff timelines, active DPS, training, lobby/rank badges, hotkeys, click-through and updates. Supporters receive storage/nameplate benefits. | Luma shares selected summaries and offers bounded community rankings. Verified character badges, CP-bracket percentiles, dungeon-run grouping, per-skill buff attribution, complete lobby state and automatic updates remain unsupported. |
| [Aion2t Premium](https://aion2t.com/premium) | Target/ally cooldowns and boss cast/target/move alerts; extended uploaded history; auction information and collected genus/pet/wing data. | Luma displays received own cooldowns, windups and effects without payment. It does not substitute manual timers for validated ally/target cooldowns, or include the provider's auction/collection datasets. |

Some competing meters are free; supporter storage or website data is a separate offering. “Everything premium is implemented” would not accurately describe this preview.

## Public sharing and deployment state

The 0.13.0 source includes the native sharing client, privacy-preserving report preparation, same-app Community section and hosted report/ranking implementation. Public service activation is a separate deployment gate; an unconfigured or inaccessible service displays its state instead of reporting a successful upload or fabricated rank. Local clipboard, HTML, CSV and JSON sharing remains usable without the service.

The server checks payload shape, bounded values, arithmetic, scope and ranking context. A user-controlled summary is not an independently authenticated game log. Do not describe these records as verified world records. Public links are retained for 30 days and can be revoked earlier with the locally stored deletion key. Initial capacity is 5,000 reports / 100 MiB of report JSON, with 100 uploads per UTC day across the service and separate per-IP/read quotas; see the [exact initial limits](community-sharing.md#initial-service-limits). This is a bounded free community service, not an unlimited cloud archive.

## Independent protocol evidence and asset provenance

The pinned MIT [AionDPS frame decoder](https://github.com/SkeeveAN/Aion-DPS-Meter/blob/72417dc72457844f514729fd2680fcbbd4423a93/Client/Aion2/Protocol/Aion2FrameDecoder.cs), [opcode configuration](https://github.com/SkeeveAN/Aion-DPS-Meter/blob/72417dc72457844f514729fd2680fcbbd4423a93/Client/assets/aion2/protocol/opcodes.json), [combat-frame findings](https://github.com/SkeeveAN/Aion-DPS-Meter/blob/72417dc72457844f514729fd2680fcbbd4423a93/docs/protocol/combat-frames.md) and [field-boss decoder](https://github.com/SkeeveAN/Aion-DPS-Meter/blob/72417dc72457844f514729fd2680fcbbd4423a93/Client/Aion2/Aion2FieldBosses.cs) document relevant routes and their validation boundaries. A route being documented does not prove all later regions and versions use it unchanged.

No GPL meter implementation or external item/NPC/skill/icon catalog is bundled. The [skill-table provenance note](https://github.com/SkeeveAN/Aion-DPS-Meter/blob/72417dc72457844f514729fd2680fcbbd4423a93/Client/assets/aion2/skills/README.md) describes third-party origins; a repository-wide license does not establish redistribution rights to every embedded dataset. Runtime received names/IDs and independently created UI graphics remain separate from external catalogs.

The Windows RTT implementation follows Microsoft's [GetPerTcpConnectionEStats](https://learn.microsoft.com/en-us/windows/win32/api/iphlpapi/nf-iphlpapi-getpertcpconnectionestats) and [TCP_ESTATS_PATH_ROD_v0](https://learn.microsoft.com/en-us/windows/win32/api/tcpestats/ns-tcpestats-tcp_estats_path_rod_v0) contracts. RTT data is conditional on Windows support, permissions and fresh path samples.

## Release validation still required

Use the final executable for a synchronized solo Combat Analyzer test, an open-world run with nearby strangers and an actual party run. Verify actor names, self/party/observed totals, summon attribution and timing. Test observed pet updates, stagger, cooldown charges and TCP RTT in their own live scenarios. A real Cube scene must include audible stereo output, camera turns and other-sound negatives.

Test online publication/retrieval/filtering/revocation against the actual deployed public endpoint before calling public sharing available. Automated schema, privacy, replay and UI tests establish the cases tested; they do not establish full premium parity, worldwide data coverage or universal sound-detection accuracy.
