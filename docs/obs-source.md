# Local OBS browser source

The OBS source is optional and starts only when enabled in Luma. Add the displayed URL as a Browser Source in OBS on the same computer. Choose Personal, Party or Observed players explicitly; names are hidden by default. Personal totals use the character's own clock. Party totals require received or explicitly selected membership, while an unresolved identity shows unknown values.

The source uses only Luma's current received snapshot. It does not start packet capture, upload encounters, contact another meter, open a game account or install a service. The page has an independent compact design, transparent outer background, class bars, totals, duration and capture/loss information. Names are inserted as text. Hidden names are also removed from target/build/capture metadata rather than hidden only with CSS.

Total damage and DPS have separate labels. Rates above 1,000 stay in K/s, including values above one million, while total damage retains compact K/M units. A nonzero damage snapshot without positive measured duration shows unavailable DPS rather than presenting its total as a rate.

The listener binds only to 127.0.0.1. There is no LAN mode or firewall change in this version. Every page, script, stylesheet and data request requires a random per-start 128-bit token generated by Windows. Restarting the source changes its URL and invalidates the previous one. Stopping Luma closes its listener; it is not a permanent background server.

Requests accept only GET, exact local Host and a matching Origin when supplied. Headers, response data, timing, player counts and alias retention are bounded. The server serves embedded assets and its allowlisted live snapshot, never arbitrary disk paths. The page uses no external scripts, fonts, analytics or images. Security tests cover authorization, malformed requests, scope/privacy, stable anonymous names, random tokens and shutdown with a stalled client.

This source currently supports OBS on the same computer. A second-PC source would require a separately designed LAN access setting; copying the loopback URL to another machine does not connect it to Luma.
