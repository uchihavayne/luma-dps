# AION 2 class artwork

These are the nine game class images used by Aion DPS Meter, copied byte for byte from
[SkeeveAN/Aion-DPS-Meter](https://github.com/SkeeveAN/Aion-DPS-Meter/tree/f7abcbf6ba0a4c5f85ca93d4abb89b5fb65c5eee/Client/assets/aion2/classes), revision `f7abcbf6ba0a4c5f85ca93d4abb89b5fb65c5eee`.
The upstream software is MIT licensed; see `dependency-notices/aion-dps-meter-MIT.txt`.
AION 2 names, trademarks and game artwork belong to NCSOFT. The software license does not transfer ownership of game artwork; these images are excluded from Luma's original artwork claim.

The upstream filenames `elementalist` and `fighter` map to Spiritmaster and Brawler respectively. Chanter and Ranger have their own images. Unknown classes use a neutral indicator, never a guessed class image. No network request is needed at runtime.
